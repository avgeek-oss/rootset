Rootset gives your team one place for structured data. The browser, REST API and MCP use the same tables and permissions.

<Steps>
  <Step title="Install and claim your workspace">
    Follow the [image-based installation](/self-hosting/installation). Open the
    UI, enter the installation secret, and create the first administrator and
    workspace. The first administrator is verified automatically. SMTP is used
    for later invitations and account emails.
  </Step>
  <Step title="Create a database and table">
    Select **Create database**, give it a name, and open it. Select **Create
    Table** to create your first table. In its **Settings → Fields**, add the
    columns your application needs, such as `NAME` (text), `STOCK` (integer) and
    `ACTIVE` (boolean).
  </Step>
  <Step title="Populate the table">
    Create rows through the [REST API](/api-guide) or an [MCP
    client](/mcp-guide). Rootset's browser edits existing rows; it has no Add
    row or import action.
  </Step>
  <Step title="Edit and review">
    Open the table and double-click a cell to edit it. Right-click for **Set to
    NULL**, **View cell history** or **Delete row**. Rootset keeps the last 200
    saved changes per existing cell. Use **Cmd+Z** (Ctrl+Z on Windows/Linux) to
    undo saved cell edits in the current table session, one at a time.
  </Step>
</Steps>
