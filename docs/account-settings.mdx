The profile popover groups **Profile**, **Preferences**, **Auth & Security** and **My API Keys**. It also links to the changelog, documentation, repository and feedback.

Use **Profile** to change your display name. **Preferences** controls presentation settings, including date/time formats. Changing a presentation setting does not rewrite stored values; temporal data remains in UTC.

**Auth & Security** provides email/password, passkey and session settings. Add a passkey for supported devices, verify email changes, and revoke sessions you no longer recognise. Sensitive identity changes ask you to confirm your identity.

[MCP connections](/mcp-connections) and API keys are managed under the account's API & MCP settings. A backend outage uses the shared recovery page with a retry action; it does not expose raw connection errors.
