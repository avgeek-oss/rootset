Open a database and select **Create Table** at the top right. Give the table a name and optional description. Open **Settings → Fields** to define its columns.

Each table card shows the row count. Opening a table shows its spreadsheet; the secondary sidebar provides **General**, **Fields**, **Unique rules**, **Foreign keys**, **Import Requests** and **Export Requests**. The **Danger Zone** category at the end contains **Delete Table**.

## General settings

Change the table's name and description in **General**. Renaming keeps its opaque ID and rows intact. Members can create and edit tables and fields.

## Delete a table

An Admin can delete a table from **Danger Zone → Delete Table**. This removes the table, rows, fields, unique rules and cell history. A Member cannot delete tables or databases. Deletion has no undo or in-app restore.

## Populate a table

Select **Add record** to create a record, or use [Import Requests](/import-requests) to append CSV or JSONL records. REST and MCP support the same typed validation. Use [saved views](/saved-views) to keep named filters, sorting and column layouts.
