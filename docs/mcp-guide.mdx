Use your installation's public **API** URL followed by `/mcp`, such as `https://rootset-api.example.com/mcp`. The UI URL is a separate address.

Add the server in your MCP client, sign in to Rootset in the browser, and review the requested access. MCP uses OAuth; you do not need an API key or a custom authentication header.

## Connect your client

<Tabs>
  <Tab title="Codex">
    Add the server to `~/.codex/config.toml`:

    ```toml
    [mcp_servers.rootset]
    url = "https://rootset-api.example.com/mcp"
    ```

    Then start browser sign-in:

    ```bash
    codex mcp login rootset
    ```

    Remove any old `bearer_token_env_var` or custom authentication headers before switching from an API-key configuration.

  </Tab>
  <Tab title="Cursor">
    Add the server to `.cursor/mcp.json`, then connect and follow the browser sign-in prompt:

    ```json
    {
      "mcpServers": {
        "rootset": { "url": "https://rootset-api.example.com/mcp" }
      }
    }
    ```

  </Tab>
  <Tab title="VS Code">
    Add the server to `.vscode/mcp.json`, start it from the MCP controls, and follow the authorization prompt:

    ```json
    {
      "servers": {
        "rootset": {
          "type": "http",
          "url": "https://rootset-api.example.com/mcp"
        }
      }
    }
    ```

  </Tab>
  <Tab title="Claude Code">
    Add the remote server:

    ```bash
    claude mcp add --transport http rootset 'https://rootset-api.example.com/mcp'
    ```

    Open `/mcp` in Claude Code and select Rootset to sign in.

  </Tab>
</Tabs>

Replace the example API URL with your own installation. Other clients need Streamable HTTP and OAuth support.

## Choose access

The consent form starts with **Read-only**. Choose **Write** or **Administrator** if needed and available for your workspace role. Administrator access requires an administrator account and recent identity confirmation.

Role changes and membership removal revoke existing MCP connections. Sign in again to approve access under your new role. You can revoke a connection in **Account Settings → MCP connections**.

## Try a workflow

Ask your client to find the workspace, list its databases and tables, and read a table's schema. It can then query records or make changes within the access you approved.

The **MCP reference** groups individual tools by purpose. Each tool page includes its arguments, an example call, permissions and the corresponding REST operation. For jobs such as exports or schema changes, check the job's result before treating the work as complete.

Use [API keys](/api-keys) for REST integrations that need a personal or team credential.
