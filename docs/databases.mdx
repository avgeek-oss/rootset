On **Databases**, select **Create database**, enter a name and optional description, then create it. Each database card shows its table count. Open a card to see its tables.

## Change database details

Open the database's **General** settings to change its name or description. Admins and Members can create and edit databases.

## Delete a database

Only an Admin can delete databases. Open **Settings → Danger Zone**, select **Delete database**, and confirm your identity with a password or passkey. Deletion removes its tables, rows, fields and cell histories. There is no undo or in-app restore. API/MCP administrator credentials execute the authorised deletion directly.

Database URLs use `/databases/{databaseId}`. IDs remain stable when you rename a database.
