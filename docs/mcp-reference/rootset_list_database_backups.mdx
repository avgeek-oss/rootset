## Access and behavior

Requires a current workspace role of **Admin** or higher. The connection needs `backups:read` scope.

- This tool reads data without changing it.

## Arguments

| Argument     | Required | Type           | Details                                         |
| ------------ | -------- | -------------- | ----------------------------------------------- |
| `orgId`      | Yes      | string         | Workspace ID returned by rootset_get_context.   |
| `databaseId` | Yes      | string         | ID of the database to work with.                |
| `limit`      | No       | integer        | Maximum number of items to return.              |
| `cursor`     | No       | string or null | Continuation cursor from the previous response. |
