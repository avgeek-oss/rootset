## Access and behavior

Requires a current workspace role of **Viewer** or higher.

- This tool reads data without changing it.

## Arguments

| Argument      | Required | Type   | Details                                                           |
| ------------- | -------- | ------ | ----------------------------------------------------------------- |
| `preferences` | Yes      | object | —                                                                 |
| `value`       | Yes      | string | UTC instant with mandatory Z and at most three fractional digits. |

## Example call

Your client initializes the MCP connection before this call. Example identifiers and values are illustrative; use the IDs, schema version and values from your installation.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "rootset_preview_preferences",
    "arguments": {
      "preferences": {
        "timezone": "UTC",
        "locale": "en-GB",
        "dateFormat": "day-short-month-year",
        "timeFormat": "24-hour",
        "theme": "system"
      },
      "value": "2024-01-01T12:30:00.000Z"
    }
  }
}
```
