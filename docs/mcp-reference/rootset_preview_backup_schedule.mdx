```mermaid
flowchart LR
```

## Access and behavior

Requires a current workspace role of **Admin** or higher. The connection needs `backups:read` scope.

- This tool reads data without changing it.

## Arguments

| Argument     | Required | Type   | Details                                       |
| ------------ | -------- | ------ | --------------------------------------------- |
| `cron`       | Yes      | string | —                                             |
| `timezone`   | Yes      | string | —                                             |
| `orgId`      | Yes      | string | Workspace ID returned by rootset_get_context. |
| `databaseId` | Yes      | string | ID of the database to work with.              |

<Accordion title="Complete input schema">

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "properties": {
    "cron": {
      "type": "string",
      "maxLength": 120,
      "pattern": "^[\\d*/,\\-]+(?:\\s+[\\d*/,\\-]+){4}$"
    },
    "timezone": {
      "type": "string",
      "maxLength": 100
    },
    "orgId": {
      "type": "string",
      "pattern": "^[0-7][0-9A-HJKMNP-TV-Z]{25}$"
    },
    "databaseId": {
      "type": "string",
      "pattern": "^[0-7][0-9A-HJKMNP-TV-Z]{25}$"
    }
  },
  "required": ["cron", "timezone", "orgId", "databaseId"],
  "additionalProperties": false
}
```

</Accordion>

## Example call

Your client initializes the MCP connection before this call. Example identifiers and values are illustrative; use the IDs, schema version and values from your installation.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "rootset_preview_backup_schedule",
    "arguments": {
      "cron": "* * * * *",
      "timezone": "UTC",
      "orgId": "01K6J7B8000000000000000000",
      "databaseId": "01K6J7B8000000000000000000"
    }
  }
}
```
