## Access and behavior

Requires a current workspace role of **Viewer** or higher. The connection needs `viewer` scope.

- This tool reads data without changing it.

## Arguments

| Argument      | Required | Type           | Details                                                                      |
| ------------- | -------- | -------------- | ---------------------------------------------------------------------------- |
| `orgId`       | Yes      | string         | Organisation ID returned by rootset_get_context.                             |
| `databaseId`  | Yes      | string         | ID of the database to work with.                                             |
| `tableId`     | Yes      | string         | ID of the table to work with.                                                |
| `rowId`       | No       | string         | Stable record ID, not its position in the spreadsheet.                       |
| `fieldId`     | No       | string         | ID of the field to work with.                                                |
| `mutationId`  | No       | string         | —                                                                            |
| `from`        | No       | string         | UTC instant with mandatory Z and at most three fractional digits.            |
| `to`          | No       | string         | UTC instant with mandatory Z and at most three fractional digits.            |
| `limit`       | No       | integer        | Maximum number of items to return.                                           |
| `cursor`      | No       | string or null | Continuation cursor from the previous response.                              |
| `workspaceId` | Yes      | string         | Workspace ID returned by rootset_list_workspaces; required even for Default. |
