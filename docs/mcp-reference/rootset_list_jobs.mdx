## Access and behavior

Requires a current workspace role of **Viewer** or higher. The connection needs `jobs:read` scope.

- This tool reads data without changing it.

## Arguments

| Argument     | Required | Type                                                                                     | Details                                         |
| ------------ | -------- | ---------------------------------------------------------------------------------------- | ----------------------------------------------- |
| `orgId`      | Yes      | string                                                                                   | Workspace ID returned by rootset_get_context.   |
| `limit`      | No       | integer                                                                                  | Maximum number of items to return.              |
| `cursor`     | No       | string or null                                                                           | Continuation cursor from the previous response. |
| `databaseId` | No       | string                                                                                   | ID of the database to work with.                |
| `tableId`    | No       | string                                                                                   | ID of the table to work with.                   |
| `state`      | No       | "queued" or "running" or "succeeded" or "failed" or "cancelled" or "partially_completed" | —                                               |
| `kind`       | No       | string                                                                                   | —                                               |
| `order`      | No       | "asc" or "desc"                                                                          | —                                               |
