## Access and behavior

Use a personal OAuth connection for the signed-in account. The connection needs `profile:manage` scope.

- This tool changes data or starts work. Confirm the target and input before calling it.
- Keep the same `idempotencyKey` when retrying an unchanged request; use a new key for different input.

## Arguments

| Argument         | Required | Type                                                                                                         | Details                                                            |
| ---------------- | -------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ |
| `timezone`       | No       | string                                                                                                       | —                                                                  |
| `locale`         | No       | string                                                                                                       | —                                                                  |
| `dateFormat`     | No       | "day-short-month-year" or "short-month-day-year" or "year-month-day" or "day-month-year" or "month-day-year" | —                                                                  |
| `timeFormat`     | No       | "24-hour" or "12-hour" or "24-hour-seconds" or "12-hour-seconds"                                             | —                                                                  |
| `theme`          | No       | "system" or "light" or "dark"                                                                                | —                                                                  |
| `idempotencyKey` | Yes      | string                                                                                                       | Stable caller-provided key across retries of this exact operation. |
