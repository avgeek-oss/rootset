## Access and behavior

Requires a current workspace role of **Admin** or higher. Use a personal OAuth connection for the signed-in account. The connection needs `admin` scope.

- This tool changes data or starts work. Confirm the target and input before calling it.
- Keep the same `idempotencyKey` when retrying an unchanged request; use a new key for different input.

## Arguments

| Argument         | Required | Type             | Details                                                                      |
| ---------------- | -------- | ---------------- | ---------------------------------------------------------------------------- |
| `orgId`          | Yes      | string           | Organisation ID returned by rootset_get_context.                             |
| `id`             | Yes      | string           | —                                                                            |
| `overlapSeconds` | No       | integer          | —                                                                            |
| `name`           | No       | string           | —                                                                            |
| `access`         | No       | "read" or "edit" | —                                                                            |
| `includeAdmin`   | No       | boolean          | —                                                                            |
| `expiresAt`      | No       | string or null   | —                                                                            |
| `workspaceId`    | Yes      | string           | Workspace ID returned by rootset_list_workspaces; required even for Default. |
| `idempotencyKey` | Yes      | string           | Stable caller-provided key across retries of this exact operation.           |
