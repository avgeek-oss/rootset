## Workflow

```mermaid
flowchart LR
  discover["Read the table schema"] --> invoke["Preview schema change"]
  invoke --> outcome["Read the result"]
```

## Access and behavior

Requires a current workspace role of **Admin** or higher. The connection needs `schema:manage` scope.

- This tool reads data without changing it.
- Read the current table schema before supplying `expectedSchemaVersion`.

## Arguments

| Argument                | Required | Type       | Details                                                                      |
| ----------------------- | -------- | ---------- | ---------------------------------------------------------------------------- |
| `orgId`                 | Yes      | string     | Organisation ID returned by rootset_get_context.                             |
| `databaseId`            | Yes      | string     | ID of the database to work with.                                             |
| `tableId`               | Yes      | string     | ID of the table to work with.                                                |
| `expectedSchemaVersion` | Yes      | integer    | Current version returned by the table schema.                                |
| `change`                | Yes      | JSON value | —                                                                            |
| `workspaceId`           | Yes      | string     | Workspace ID returned by rootset_list_workspaces; required even for Default. |

```json
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "rootset_preview_schema_change",
    "arguments": {
      "orgId": "01K6J7B8000000000000000000",
      "databaseId": "01K6J7B8000000000000000000",
      "tableId": "01K6J7B8000000000000000000",
      "expectedSchemaVersion": 1,
      "change": {
        "kind": "add_field",
        "field": {}
      },
      "workspaceId": "01K6J7B8000000000000000000"
    }
  }
}
```
