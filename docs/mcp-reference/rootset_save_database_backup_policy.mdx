## Access and behavior

Requires a current workspace role of **Admin** or higher. The connection needs `backups:manage` scope.

- This tool changes data or starts work. Confirm the target and input before calling it.
- Keep the same `idempotencyKey` when retrying an unchanged request; use a new key for different input.

## Arguments

| Argument              | Required | Type            | Details                                                            |
| --------------------- | -------- | --------------- | ------------------------------------------------------------------ |
| `expectedVersion`     | Yes      | integer         | —                                                                  |
| `retentionCount`      | Yes      | integer or null | —                                                                  |
| `overdueGraceMinutes` | Yes      | integer         | —                                                                  |
| `orgId`               | Yes      | string          | Workspace ID returned by rootset_get_context.                      |
| `databaseId`          | Yes      | string          | ID of the database to work with.                                   |
| `idempotencyKey`      | Yes      | string          | Stable caller-provided key across retries of this exact operation. |
