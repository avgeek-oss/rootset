## Workflow

```mermaid
flowchart LR
  discover["Read the table schema"] --> invoke["Count rows"]
  invoke --> outcome["Check the job result"]
```

## Access and behavior

Requires a current workspace role of **Viewer** or higher. The connection needs `rows:read` scope.

- This tool reads data without changing it.
- A returned job is pending work. Use [rootset_get_job](/mcp-reference/rootset_get_job) to check its final result.

## Arguments

| Argument     | Required | Type    | Details                                       |
| ------------ | -------- | ------- | --------------------------------------------- |
| `orgId`      | Yes      | string  | Workspace ID returned by rootset_get_context. |
| `databaseId` | Yes      | string  | ID of the database to work with.              |
| `tableId`    | Yes      | string  | ID of the table to work with.                 |
| `query`      | No       | object  | —                                             |
| `exact`      | No       | boolean | —                                             |
