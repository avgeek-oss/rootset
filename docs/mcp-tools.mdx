---
title: "MCP tools"
description: "Current tools and minimum workspace roles generated from the public operation contract."
---

Rootset exposes the same operations through REST and MCP. Minimum roles below describe product authority; your credential must also carry the operation scopes. Personal account operations require a personal identity.

| Tool                              | Action                                                                                                                                                                                                                                                                                                                                              | Minimum role |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| `rootset_get_context`             | Get the caller, installation organisation, current role capabilities and preferences.                                                                                                                                                                                                                                                               | viewer       |
| `rootset_get_profile`             | Read your profile.                                                                                                                                                                                                                                                                                                                                  | viewer       |
| `rootset_update_profile`          | Update your display name.                                                                                                                                                                                                                                                                                                                           | viewer       |
| `rootset_get_preferences`         | Read display preferences.                                                                                                                                                                                                                                                                                                                           | viewer       |
| `rootset_update_preferences`      | Update timezone, locale, format or theme preferences.                                                                                                                                                                                                                                                                                               | viewer       |
| `rootset_get_preference_options`  | List supported preference values.                                                                                                                                                                                                                                                                                                                   | viewer       |
| `rootset_preview_preferences`     | Preview a UTC instant with proposed display preferences.                                                                                                                                                                                                                                                                                            | viewer       |
| `rootset_list_sessions`           | List your active browser sessions without session secrets.                                                                                                                                                                                                                                                                                          | viewer       |
| `rootset_revoke_session`          | Revoke an owned browser session.                                                                                                                                                                                                                                                                                                                    | viewer       |
| `rootset_list_connections`        | List your delegated OAuth connections.                                                                                                                                                                                                                                                                                                              | viewer       |
| `rootset_revoke_connection`       | Revoke an owned OAuth grant and refresh family.                                                                                                                                                                                                                                                                                                     | viewer       |
| `rootset_get_organisation`        | Read an authorised organisation.                                                                                                                                                                                                                                                                                                                    | viewer       |
| `rootset_update_organisation`     | Update the installation organisation name.                                                                                                                                                                                                                                                                                                          | admin        |
| `rootset_list_members`            | List organisation members.                                                                                                                                                                                                                                                                                                                          | admin        |
| `rootset_update_member`           | Update a member name or role while preserving at least one admin.                                                                                                                                                                                                                                                                                   | admin        |
| `rootset_remove_member`           | Remove a member and invalidate delegated access.                                                                                                                                                                                                                                                                                                    | admin        |
| `rootset_list_invitations`        | List redacted organisation invitations.                                                                                                                                                                                                                                                                                                             | admin        |
| `rootset_invite_member`           | Invite a member as an admin with email proof.                                                                                                                                                                                                                                                                                                       | admin        |
| `rootset_cancel_invitation`       | Cancel an invitation before acceptance.                                                                                                                                                                                                                                                                                                             | admin        |
| `rootset_list_personal_keys`      | List metadata for your personal keys.                                                                                                                                                                                                                                                                                                               | viewer       |
| `rootset_create_personal_key`     | Create a personal key with read-only, edit or administrative permissions capped by your live role; secret appears once.                                                                                                                                                                                                                             | viewer       |
| `rootset_rotate_personal_key`     | Rotate a personal key with bounded overlap and one-time secret display; preserve name, permissions and expiry unless explicitly changed.                                                                                                                                                                                                            | viewer       |
| `rootset_revoke_personal_key`     | Revoke an owned personal key.                                                                                                                                                                                                                                                                                                                       | viewer       |
| `rootset_list_team_keys`          | List metadata for workspace-owned API keys. Administrators only.                                                                                                                                                                                                                                                                                    | admin        |
| `rootset_create_team_key`         | Create a workspace-owned API key with explicit permissions and expiry; the secret appears once and access is independent of its creator.                                                                                                                                                                                                            | admin        |
| `rootset_rotate_team_key`         | Rotate a workspace API key with bounded overlap; preserve permissions and expiry unless explicitly changed. Administrators only.                                                                                                                                                                                                                    | admin        |
| `rootset_revoke_team_key`         | Revoke a workspace-owned API key. Administrators only.                                                                                                                                                                                                                                                                                              | admin        |
| `rootset_get_security_status`     | Read factor status and credential metadata only.                                                                                                                                                                                                                                                                                                    | viewer       |
| `rootset_list_databases`          | List accessible logical databases.                                                                                                                                                                                                                                                                                                                  | viewer       |
| `rootset_create_database`         | Create a logical database with a managed PostgreSQL namespace.                                                                                                                                                                                                                                                                                      | member       |
| `rootset_get_database`            | Read a database within its full organisation parent.                                                                                                                                                                                                                                                                                                | viewer       |
| `rootset_update_database`         | Update database presentation metadata.                                                                                                                                                                                                                                                                                                              | member       |
| `rootset_delete_database`         | Start administrator database deletion, removing its tables, rows and cell history.                                                                                                                                                                                                                                                                  | admin        |
| `rootset_list_tables`             | List accessible tables inside a database.                                                                                                                                                                                                                                                                                                           | viewer       |
| `rootset_create_table`            | Create a physical typed table and runtime schema metadata.                                                                                                                                                                                                                                                                                          | member       |
| `rootset_get_table`               | Read table metadata including cached live-row count.                                                                                                                                                                                                                                                                                                | viewer       |
| `rootset_update_table`            | Update table name and description.                                                                                                                                                                                                                                                                                                                  | member       |
| `rootset_delete_table`            | Start administrator table deletion, removing its rows and cell history.                                                                                                                                                                                                                                                                             | admin        |
| `rootset_get_table_schema`        | Discover active fields, rules, limits and operator coverage.                                                                                                                                                                                                                                                                                        | viewer       |
| `rootset_list_fields`             | List active fields by property name and stable identifier.                                                                                                                                                                                                                                                                                          | viewer       |
| `rootset_create_field`            | Add a validated field, checking existing values and row bytes.                                                                                                                                                                                                                                                                                      | member       |
| `rootset_update_field`            | Change field definition with explicit existing-data validation and conversion.                                                                                                                                                                                                                                                                      | member       |
| `rootset_delete_field`            | Remove a field safely after approving dependent unique-rule removal.                                                                                                                                                                                                                                                                                | member       |
| `rootset_reorder_fields`          | Set field presentation order without changing API keys.                                                                                                                                                                                                                                                                                             | member       |
| `rootset_preview_schema_change`   | Dry run a proposed schema change over existing values.                                                                                                                                                                                                                                                                                              | admin        |
| `rootset_apply_schema_change`     | Start a journalled resumable schema change with verified cutover.                                                                                                                                                                                                                                                                                   | member       |
| `rootset_get_schema_operation`    | Inspect a schema journal using its journal ID or the originating schema job ID. Reports preserve recovery state and public business definitions without physical identifiers.                                                                                                                                                                       | member       |
| `rootset_list_unique_rules`       | List active or building scalar uniqueness rules.                                                                                                                                                                                                                                                                                                    | viewer       |
| `rootset_create_unique_rule`      | Validate the whole table and activate collision-safe scalar uniqueness.                                                                                                                                                                                                                                                                             | member       |
| `rootset_delete_unique_rule`      | Remove uniqueness enforcement and update the schema version.                                                                                                                                                                                                                                                                                        | member       |
| `rootset_list_rows`               | List rows with compact projection/order/cursor parameters.                                                                                                                                                                                                                                                                                          | viewer       |
| `rootset_create_row`              | Commit a validated row, uniqueness, capacity, initial cell history and idempotency.                                                                                                                                                                                                                                                                 | member       |
| `rootset_query_rows`              | Query typed fields with bounded projection, filters, sorting and live cursors.                                                                                                                                                                                                                                                                      | viewer       |
| `rootset_get_row`                 | Get one canonical row with its opaque ID and decimal-string revision.                                                                                                                                                                                                                                                                               | viewer       |
| `rootset_update_row`              | Patch cells with optimistic revision checks and atomic history.                                                                                                                                                                                                                                                                                     | member       |
| `rootset_delete_row`              | Delete a row with If-Match revision, remove its cell history and release live capacity.                                                                                                                                                                                                                                                             | member       |
| `rootset_list_row_comments`       | Read a row discussion in chronological cursor pages of up to 50 entries, including deleted comments with an empty body and a deletedAt timestamp. Requires current access to the row.                                                                                                                                                               | viewer       |
| `rootset_create_row_comment`      | Add a plain-text comment of up to 4096 characters with authenticated attribution. Returns its ID; idempotent retries never retain or resurrect deleted bodies. Does not change row or schema versions.                                                                                                                                              | member       |
| `rootset_count_row_comments`      | Read discussion entry counts, including deleted comments, for at most 200 visible rows in one batch. Missing rows are omitted; existing rows without comments return zero.                                                                                                                                                                          | viewer       |
| `rootset_delete_row_comment`      | Permanently clear your own comment's body, or moderate as an administrator, while retaining its author, creation time and deletion timestamp in the discussion. Requires current write access to the row. Deleted entries cannot be edited, restored or removed through comment operations.                                                         | member       |
| `rootset_mutate_rows`             | Commit at most 1,000 create/update/delete mutations atomically. With repair, accept only revision-bound updates as a durable operator repair job; require a personal admin with installation:manage and rows:write, current permission checks for the target, schema, revisions, values and reason. Ordinary batches return the synchronous result. | member       |
| `rootset_get_table_statistics`    | Read counts and size estimates without counting every filtered page.                                                                                                                                                                                                                                                                                | viewer       |
| `rootset_count_rows`              | Get an explicitly labelled count; expensive exact filtered counts become jobs.                                                                                                                                                                                                                                                                      | viewer       |
| `rootset_get_cell_history`        | Read the latest 200 saved changes for an existing cell.                                                                                                                                                                                                                                                                                             | viewer       |
| `rootset_query_history`           | Query bounded row/table history under current resource access.                                                                                                                                                                                                                                                                                      | viewer       |
| `rootset_get_mutation`            | Inspect a committed mutation without replaying one-time secrets.                                                                                                                                                                                                                                                                                    | viewer       |
| `rootset_export_rows`             | Start a complete-table snapshot export in CSV or JSONL, including every row and field, with checksummed artifacts.                                                                                                                                                                                                                                  | viewer       |
| `rootset_get_artifact`            | Get authenticated expiring artifact access after current source/target permission checks.                                                                                                                                                                                                                                                           | viewer       |
| `rootset_list_jobs`               | List only currently authorised jobs and their truthful progress.                                                                                                                                                                                                                                                                                    | viewer       |
| `rootset_get_job`                 | Inspect a durable job and committed checkpoints.                                                                                                                                                                                                                                                                                                    | viewer       |
| `rootset_cancel_job`              | Request cancellation at a safe checkpoint with partial outcomes.                                                                                                                                                                                                                                                                                    | viewer       |
| `rootset_retry_job`               | Retry an authorised recoverable job after reconciliation.                                                                                                                                                                                                                                                                                           | viewer       |
| `rootset_get_usage`               | Read appropriately redacted organisation usage and capacity.                                                                                                                                                                                                                                                                                        | viewer       |
| `rootset_get_view_preferences`    | Read your accessible table column/filter preferences.                                                                                                                                                                                                                                                                                               | viewer       |
| `rootset_update_view_preferences` | Save table view preferences without changing data/schema.                                                                                                                                                                                                                                                                                           | viewer       |
