# Towbar authentication UI adaptation

Rootset adapts the authentication frame and credentials-form patterns from `avgeek-inc/towbar`, commit `bf3354d7e3c9a8d9ec634b5057fd42a11b6edba2`, package `packages/identity-web-ui`.

Towbar distributes this source under the Apache License, Version 2.0. A copy is included in [LICENSE-Towbar](LICENSE-Towbar). The modified Rootset source identifies the adaptation. Rootset changes the product identity, layout tokens, public HeroUI controls, verification/invitation flows, error and pending behavior, and security interactions. It includes no private HeroUI Pro package, Towbar credentials, remote image dependency, or production identity configuration.
