# Towbar email adaptation

Rootset's React Email shell adapts the account-message layout and rendering pattern from `avgeek-inc/towbar`, commit `bf3354d7e3c9a8d9ec634b5057fd42a11b6edba2`, file `packages/towbar-email/src/index.tsx`.

Towbar distributes this source under the Apache License, Version 2.0. A copy is included in [LICENSE-Towbar](LICENSE-Towbar). The modified Rootset source identifies the adaptation. Rootset replaces the name, links, colors, fonts, organisation context and security messages, and imports only public React Email packages. It includes no Towbar credentials, private packages or production image/font dependency.
