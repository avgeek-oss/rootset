# Operations

Admins manage installation settings, people, schema and recovery. PostgreSQL
deployment credentials remain separate from product roles.

- [Install locally or configure external services](installation.md)
- [Fresh baseline and installation recovery](upgrade-and-recovery.md)
- [Operation progress and dependencies](jobs-and-dependencies.md)
- [Keys and account recovery](keys-and-recovery.md)
- [Admin data correction](operator-repair.md)

Use the [verification guide](../verification/README.md) for rehearsals with
isolated synthetic data. Test logs, browser captures, benchmark reports and
recovery comparisons should identify the version and behavior under review.
Earlier receipts and obsolete multi-organisation procedures remain historical.
They do not establish a supported upgrade from earlier prelaunch schemas.
